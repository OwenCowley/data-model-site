Product

Everything your model means, in one governed workspace

A CLI and a browser workspace built on the same engine. Design the model, review it like code, and check it against the warehouse and catalog.

Model

Models as code, with diagrams people can read

Entities, attributes, keys and relationships live in YAML or JSON files with stable IDs. The workspace renders them as editable lists and an entity diagram.

  • Relational, Kimball and Data Vault 2.0 profiles
  • Concepts and definitions linked to every entity
  • Deterministic formatting that diffs cleanly in Git

Validate

Catch modelling mistakes before they ship

Validation checks references, keys, grains and method rules, and reports every finding with a stable code. Unsupported semantics are flagged, never silently dropped.

  • Broken references and duplicate IDs
  • Missing grains, keys and history types
  • Machine-readable JSON output for CI

Reconcile

See where deployed reality drifts from the design

Normalise dbt, Databricks and Atlan metadata, then compare it with the approved model. Intent, catalog, deployment and runtime evidence stay separate, so observations never overwrite meaning.

  • Type, nullability and coverage mismatches
  • Unknowns reported as unknowns, not as missing assets
  • Structured comparison across sources

Ontology

A business ontology that AI can trust

Publish deterministic JSON-LD releases with SHA-256 manifests. Every table and field links to a concept with a stable URI, so meaning survives renames and refactors.

  • Reproducible releases with content hashes
  • Concept URIs preserved through renames
  • Semantic diffs between revisions

Semantic layer

Governed metrics and context for AI agents

Define dimensions, measures and metrics next to the model, then export them as structured context for text-to-SQL and AI analysts.

  • Definitions validated against the model
  • Exports that work without an LLM or network
  • Bring your own AI tools

Authoring

Start from the metadata you already have

Edit models in the browser, or draft them from dbt and Databricks metadata. Proposals are previewed before adoption and never overwrite your source files.

  • Round-trip YAML and JSON
  • Reviewable import proposals
  • Download drafts as files
