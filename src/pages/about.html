About

Meaning deserves a source of truth

Warehouses grow faster than anyone can document them, and AI tools now read whatever they find. We're building a workspace where the intended model is explicit, versioned and checked against reality.

Principles

Intent is not observation

The approved model, catalog snapshots, deployments and runtime evidence are separate sources. We never overwrite meaning with what we happen to see.

Local-first

The core runs offline, with no cloud account, paid plan or LLM required.

Portable by default

Models are plain files in your Git repository. Leaving is always free.

Honest about unknowns

Missing coverage is not evidence of a missing asset, and a foreign key is not lineage. We say what we can't see.

Roadmap

  1. Now

    Local workspace

    CLI and browser workspace with validation, diffs, ontology export and offline normalisers.

  2. Next

    Live connectors and PR checks

    Read-only Databricks and dbt connectors, and drift checks on every pull request.

  3. Later

    Hosted team workspaces

    Managed scans, shared review, and governed AI-context endpoints.
