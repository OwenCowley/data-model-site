Getting started

Run the workspace locally, validate the sample model and see a reconciliation report in a few minutes.

Requirements

  • Node.js 22.12 or newer and npm
  • Git
  • No cloud account, network access or LLM is required

Install

git clone <repository-url> data-model
cd data-model
npm ci
npm run check

npm run check type-checks the workspace and runs the full test suite.

Validate a model

npm run dm -- validate examples/sales.model.yaml --json
npm run dm -- format examples/sales.model.yaml
npm run dm -- diff examples/sales.model.yaml examples/sales.model.yaml

validate reports findings with stable codes and exits non-zero on errors, so it can gate CI. format prints deterministic JSON to stdout and never overwrites source files. diff compares revisions by stable ID, so renames are reported as renames.

Model files

A model is a YAML or JSON file using the experimental 0.1.0-draft contract. Every concept, entity, attribute, key and relationship has a stable ID.

spec_version: "0.1.0-draft"
project:
  id: p001
  name: Synthetic sales
  profiles: [relational, kimball]
  ontology_namespace: "https://example.org/sales/"
concepts:
  - id: c001
    uri: "https://example.org/sales/Customer"
    name: Customer
    definition: A party that has placed an order.
entities:
  - id: e001
    name: dim_customer
    level: physical
    profile: kimball
    role: dimension
    realizes: c001
    history: { type: scd1 }
    attributes:
      - { id: a001, name: customer_key, type: integer, nullable: false }
    keys:
      - { id: k001, role: primary, attributes: [a001] }

Ontology releases

npm run dm -- ontology examples/sales.model.yaml \
  --release examples/ontology-release.json --bundle

Produces a deterministic JSON-LD release with a SHA-256 manifest. The same input always produces the same bytes.

Reconcile metadata

npm run dm -- dbt examples/dbt/input.json
npm run dm -- databricks examples/databricks/input.json
npm run dm -- atlan examples/atlan/input.json
npm run dm -- reconcile examples/evidence/input.json
npm run dm -- compare examples/comparison/input.json

Normalisers read exported metadata files and keep unknowns explicit. reconcile checks supplied evidence against the approved model; the bundled demo deliberately reports two errors and exits with status 1.

Browser workspace

npm run web:dev
# open http://127.0.0.1:4173

The workspace exposes the same engines as the CLI: Model, Diagram, Specification, Ontology, Changes, Findings, Evidence, Comparison, Semantic and Authoring.

Current limits

  • Bundled examples are synthetic fixtures; no production compatibility is claimed.
  • Connectors read exported files; live read-only connectors are in development.
  • Models are single files; multi-file projects are planned.
  • The file contract is a draft and may change before 1.0.
